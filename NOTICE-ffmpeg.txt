

==============================================================================
ffmpeg.exe
==============================================================================

ffmpeg.exe is FFmpeg, the unmodified "full" Windows build from
https://www.gyan.dev/ffmpeg/builds/ (its version is on the "ffmpeg version"
line below). It is a separate program that
wp2video.exe runs; it is not part of wp2video and is not covered by the
MIT license above.

version 3 (full text below).

Source code:

                   matching the version below, e.g. n9.0.2)
  Build and libraries used: https://www.gyan.dev/ffmpeg/builds/
